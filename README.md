# Trabalhos-IA

## Description
Repository that collects the assignments developed throughout the course **INF010484 — Artificial Intelligence**. Each folder groups the files for the respective assignment, containing material for reproduction, analysis, and visualization of results.

> Note: Some folders in this repository contain **only the files that needed to be developed or modified** for each assignment. In certain cases, an initial code base (template/framework) was provided, and only specific parts were required to be implemented or changed.

## Installation and Execution

Most of the assignments were developed using **Jupyter Notebook**.

## Requirements
- Recommended Python 3.11.2
- Jupyter Notebook
- Libraries listed in the notebooks, e.g., `numpy`, `pandas`, `scikit-learn`, `matplotlib`
